# code-mentor

Локальный ИИ-ментор по коду. Работает на модели через [Ollama](https://ollama.com),
читает файлы вашего проекта (только чтение) и отвечает на вопросы о нём.

## Быстрый старт

1. Установите [Ollama](https://ollama.com/download) и скачайте модель, например:
   `ollama pull qwen2.5-coder:3b`
2. Скопируйте `.env.example` в `.env` и при необходимости поправьте настройки.
3. Установите зависимости и запустите (нужен Python 3.13+ и [uv](https://docs.astral.sh/uv/)):

   ```
   uv sync
   uv run code-mentor
   ```

Если Ollama не запущена, программа попробует поднять `ollama serve` сама.

## Как это работает

Агент получает два инструмента: `list_files` и `read_file`. Он сам решает,
какие файлы открыть, чтобы ответить на вопрос. Ничего не изменяет и не удаляет.

- По умолчанию анализируется **текущая директория**. Другой путь задаётся через `ROOT` в `.env`.
- Пути из `SKIP` (по умолчанию `.git`, `.env`) недоступны ни для списка, ни для чтения.
- Выйти за пределы `ROOT` (`../`) нельзя.

## Настройки

Все параметры задаются в `.env`, примеры и значения по умолчанию см. в `.env.example`
и `src/code_mentor/config/settings.py`.

## Тесты

```
uv run pytest
```

## Сборка в exe

```
uv run pyinstaller code-mentor.spec
```

Файл `.env` кладётся рядом с собранным `code-mentor.exe`.
